# Employee Management System (EMS)

A simple Python-based project to manage employee data using dictionaries and functions.

##  Features
- Add Employee
- View All Employees
- Search Employee by ID
- Exit System

##  Technologies Used
- Python

##  How to Run
1. Download the .py file
2. Run using Python on any application vs code, pycharm,jupyter.
